# Dataset

## Daily Climate Time Series Data

Download the dataset from Kaggle:
https://www.kaggle.com/datasets/sumanthvrao/daily-climate-time-series-data

## Files
- DailyDelhiClimateTrain.csv — training data
- DailyDelhiClimateTest.csv — test data

## Features
- meantemp — mean temperature (target variable)
- humidity — humidity level
- wind_speed — wind speed
- meanpressure — atmospheric pressure

Do not commit the raw CSV files to GitHub.
